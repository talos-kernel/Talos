# Website media

The guardian film was generated for Talos using Higgsfield Seedance 2.0 on 2026-09-07.
It is an illustrative brand film, not a recording of an agent or its capabilities.
The 12-second source was delivered in 4K; a 24-second forward-and-return loop
avoids a jump at the repeat. The web copy is 1920 × 824, H.264, silent,
with a WebP poster. The page respects reduced motion and provides playback control.

Computer images are actual captures of the experimental workbench using synthetic
test projects. Headless was captured with the guest graphical services stopped;
the desktop capture shows a clean browser and the English welcome page.
No personal accounts, real customer data, access links or credentials appear.
Image and video metadata are excluded. Original generation records and deployment
evidence are stored privately outside this repository.
