Your first
useful run.

Install Talos, connect a model and ask for a result you can check. Start in the terminal or use your own Telegram bot.

BEFORE YOU START

Linux or macOS
Python 3.11 or newer
A supported model connection

Shell execution needs Linux bubblewrap or macOS sandbox-exec. The experimental Computer has separate requirements.

An interactive guide. Run the commands in your own terminal. This page never asks for credentials or changes your agent.

01 / INSTALL THE SIGNED RELEASE

Give it a home.

Read the installer, then run it with Bash. It downloads and verifies the release, installs dependencies and runs its checks. It starts no service.

TERMINAL
curl -fsSL https://talos-agent.ch/install.sh | less
curl -fsSL https://talos-agent.ch/install.sh | bash

Open the installed environment before running the next commands:

TERMINAL
cd ~/talos
. .venv/bin/activate
Prefer to inspect and run from source?

Use the repository and its pinned dependencies. Source features can differ from the published release.

TERMINAL
git clone https://github.com/talos-kernel/talos.git
cd talos
python3 -m venv .venv
. .venv/bin/activate
pip install --require-hashes -r requirements.lock -r requirements-dev.lock
python -m pytest tests/ -q

02 / IDENTITY & MODEL

Make it yours.

The terminal wizard records your local identity and guides you through the model connection. Telegram is optional.

TERMINAL
python -m talos setup terminal

Use the model catalogue to inspect available routes. Refresh queries the configured providers; it does not grant access to a model your account cannot use.

TERMINAL
python -m talos models
python -m talos models --refresh
python -m talos setup model
Where do credentials and permissions belong?

The wizard writes protected configuration locally. Keep your model credentials and bot token on your machine. The allowlist uses channel-qualified identities; a Telegram identity does not automatically grant terminal access.

03 / START A CONVERSATION

Open your terminal session.

Start a conversation in this terminal. The session header shows the active model and whether approvals are available.

TERMINAL
python -m talos chat

Use /help for session commands. Type exit when you are finished.

Check a setting before changing it
TERMINAL
python -m talos config list model
python -m talos config describe TALOS_STATUS_STYLE
python -m talos config validate

For an existing service, restart it after updating file settings. Process environment variables can override those settings.

Next: check a useful result ↓

04 / VERIFY THE WORK

Start with something small.

Choose a project file the agent may read. Ask for an answer grounded in that file before handing over a larger task.

Read the README in my workspace. Explain how the project starts, and point to the commands it documents.
  1. Check the source. Compare the answer with the actual README.
  2. Inspect the record. Use /log to see the tool calls and outcomes.
  3. Try a reversible change. Ask for a small notes file inside the workspace, read it back and test /undo.
Optional: a place for longer work

The experimental Talos Computer provides a persistent workspace. Headless by default; add a desktop for visual work. It needs separate provisioning and is not part of the published 0.18.1-alpha release.
